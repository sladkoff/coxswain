# Tickets

One file per piece of work to do: `NNNN-short-title.md`, numbered in sequence like the
[ADRs](../adr/). Use the [glossary](../context/coxswain.md)'s terms.

Each ticket has these sections:

- **Status**: Open, In progress, Done or Dropped.
- **Goal**: the goal it serves, e.g. G2 ([GOALS.md](../GOALS.md)).
- **What**: what should work when it's done, from the user's side.
- **Notes**: anything known so far: the UX question it answers, ADRs, open points.

When a ticket is done, set its status and mention it in the [devlog](../DEVLOG.md). Tickets are not
deleted.
